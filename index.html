Yes, absolutely. My custom middleware connects via the SAP Business One Service Layer (OData REST API), which natively supports both SAP HANA and Microsoft SQL Server database environments. If you are on an older SAP version without the Service Layer, I can build integrations using DI Server or direct DI API wrappers.

The middleware utilizes event-driven triggers. When inventory changes occur in SAP B1 (e.g., Goods Receipt, Delivery, or Stock Transfer), a webhook notifies the middleware to update the connected storefront (Shopify, WooCommerce, etc.) instantly. Additionally, we run a daily reconciliation check to ensure 100% data alignment.

The middleware is built with local failover storage and a retry queue. If your SAP B1 server goes offline or has network drops, incoming orders from your storefront are safely cached locally in a secure, encrypted database. The queue automatically retries sending the orders to SAP B1 once the connection is restored, ensuring zero lost transactions.
